# Resume

A simple and responsive personal resume website built using semantic HTML and CSS.

## 📌 About the Project

This project is a personal resume webpage that presents educational background, technical skills, projects, hobbies, and contact information in a clean and structured layout.

The project focuses on practicing:

- Semantic HTML
- CSS styling
- Responsive web design
- HTML links
- Image integration
- Page navigation

## ✨ Sections

The resume contains the following sections:

- **Profile** – Name, profile photo and professional introduction
- **About Me** – Short personal introduction
- **Education** – Academic qualifications
- **Skills** – Technical skills
- **Projects** – Personal/academic projects
- **Hobbies** – Personal interests
- **Contact** – Email, phone and location
- **Social Links** – LinkedIn and GitHub
- **Footer** – Copyright information

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🧱 HTML Structure

The webpage uses semantic HTML elements such as:

```text
<header>
<nav>
<main>
<section>
<article>
<aside>
<figure>
<address>
<footer>
````

No unnecessary `<div>` or `<span>` elements are used.

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/Divyanshu10136/Resume.git
```

2. Open the project folder:

```bash
cd Resume
```

3. Open `index.html` in a web browser.

No server or additional dependencies are required.
